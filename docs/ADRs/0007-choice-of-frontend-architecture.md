# ADR 0006 - [Choice of backend architecture]
**Statut:** ACCEPTED 
**Date:** 20/10/2026 

## CONTEXT 
We need to chose a structure for our frontend architecture. 

## DECISION
We chose the architecture "by Components"  because we are using React for the frontend.

One component will be or can used on any page. 


## CONSEQUENCES
We will need to be careful about the import and export of the said components. 

We need to change the current architecture starting today, 20th of October 2026.
